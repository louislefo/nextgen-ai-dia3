4. Root Cause Analysis & Failure Taxonomy

A rigorous taxonomy distinguishes verifiable facts from interpretive hypotheses:

Category 1: Rate Limiting & Provider Quota (Observed Facts)

Affected Model: groq:qwen/qwen3.8-27b on cases C16 and C20.

Observed Evidence: Returned HTTP status 429:

Rate limit reached for model qwen/qwen3.8-27b on output tokens per minute (OTPM): Limit 1000, Used 865, Requested 186

Root Cause: Groq enforces an aggressive 1,000 OTPM ceiling on its free tier. Paced calls still saturated the quota during chain-of-thought generation, leaving the cell in not_executed status per retry constraints.

Category 2: Syntax Enclosure Hallucination (Observed Facts)

Affected Model: openrouter:dots-studio/dots-3-note-preview:free on cases C09 and C17.

Observed Evidence: Model hallucinated markdown enclosing backticks despite prompt instructions:

```sql
SELECT COALESCE(SUM(...), 0) AS revenue_cents FROM ...
```

Root Cause: The SQLite authorizer sandbox rejects markdown decorators to prevent code injection. The token ```sql caused immediate parser rejection (sql_error).

Category 3: Completed Age Calendar Arithmetic (Hypotheses & Facts)

Affected Models: cohere/north-mini-code (0/5 on pure age), qwen3.8-27b, gpt-oss-20b.

Observed Evidence: Compact models computed age as a raw difference of years:

CAST(strftime('%Y', ref_date) AS INT) - CAST(strftime('%Y', birth_date) AS INT) = 25

Root Cause: This fails when the birthday has not yet occurred in the reference year. In contrast, gpt-oss-120b flawlessly generated the exact boundary check:

strftime('%Y', ref_date) - strftime('%Y', birth_date) - (strftime('%m-%d', ref_date) < strftime('%m-%d', birth_date)) = 25
