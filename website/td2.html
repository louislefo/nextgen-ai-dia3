1. The central finding: agreement is not correctness

Question C09 asks for revenue excluding VAT, in cents, from customers aged exactly 25 on 2026-09-26. The reference is 487,980 cents, established by peer-audited SQL and confirmed by a second, independent arithmetic method. The fixed 2-of-3 panel published 0.

Bug 1

Cohere: the age that is a birth year

Its age expression is CAST(SUBSTR(birth_date,1,4) AS INTEGER) minus a 0-or-1 correction, which is the birth year, around 2000 to 2001. It never subtracts from 2026, so … = 25 is false for every customer and the filter keeps no row.

Bug 2

Qwen: a contradictory window

It compares against o.date instead of the reference date, then writes strftime('%m-%d', date(birth_date, '+26 years')), which returns the birth month-day again. The condition becomes md ≥ birth_md AND md < birth_md, a contradiction. Zero rows again.

Why they agree

0 is an attractor, not a coincidence

Any empty filter wrapped in COALESCE(SUM(…), 0) returns 0. Two unrelated bugs converge on the same plausible figure without sharing any reasoning. Agreement on zero is therefore weak evidence by construction, and deserves a row-count check before publication.

C09

Wrong consensus → abstention

The fourth model votes 487,980 and Dots is rejected, so the tally is 2-2, below k = 3. The quorum abstains. Safety here comes from refusing to answer, not from finding the right answer. A third model sharing the 0 would have carried the wrong value to k = 3.

C19

Abstention → correct consensus

The panel split 1-1-1 (1,990 / 83,580 / 13,930) and abstained. Two more models vote 1,990, reaching 3 votes. At 1,990 cents C19 is the smallest non-zero reference of the benchmark, so a dropped predicate overshoots it sevenfold or forty-twofold rather than slightly.

C10

A shared wrong value that wins nothing

Qwen and Dots both return 119,410 against a reference of 558,980, but neither quorum validates it: the panel splits 1-1-1 and the quorum ties 2-2. The delta is 28 order lines worth 439,570 cents, placed before the birthday in the year of the customer's 26th birthday.

The price of checking, carried into TD 3

No free model is sufficient on its own for age families. Only gpt-oss-120b reached 20/20, and C09 shows that a free quorum can agree on a wrong figure while 3-of-5 only abstains. So a customer-facing or payout figure costs either one deterministic reference query (local route, 0 USD) or a paid fallback at 0.000711 USD per request (gpt-oss-120b on OpenRouter, 0.15 / 0.60 USD per M tokens, 641 in / 1,024 out), plus human sign-off on payouts.

5. Workshop modules and verification

atelier-vote.py

Drives Orchestrateur.vote_k_sur_n on four synthetic examples and on the stored traces of any single question. The contract it enforces:

  • Strict majority: n // 2 < k ≤ n, else ValueError.
  • No duplicate weight: two proposals from the same (provider, model) are refused.
  • Errors stay in n: an unavailable member cannot shrink the denominator.
  • No fabrication: below quorum the return is value: None.

atelier-routage.py

Eleven scenarios, from the seven supplied to four added for our own rule, each deciding run, defer or abstain with the TD 1 cells cited in the reason. The captured outputs in td2/pair-c/ reproduce decision for decision from the committed code.

td2/qa/verify-td2.py

Sixteen offline checks that re-derive every published figure from the traces and the database, with a vote oracle written independently of the implementation it audits. Exit code 1 on any failure, so it can gate a submission. Each check was also run against a deliberately perturbed copy of the repository to confirm it fails when a figure moves.

Limitations we state rather than hide

Twenty questions across five models support a batch-specific hypothesis, not a general error rate. F2b rests on a single cell, so "100%" there means 1/1. The 3-of-5 quorum reached 100% precision on this batch because one extra model happened to be correct on C09 and another happened to be rejected; the measured claim is that widening the panel suppressed this error, not that a quorum cannot produce a wrong consensus.
