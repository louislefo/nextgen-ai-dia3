## Step 1: Compute the 20 Reference SQL Queries (14:15 - 15:30)

> [!IMPORTANT]
> **Grade Target: R1 (2 Points)**  
> Every reference query must be calculated by running SQL on `data/boutique.sqlite` and cross-checked by another member. **Never use a value generated by an LLM as a reference.**

### SQL Conventions to Apply
1. **Target Column**: Single row, single column named `revenue_cents` (integer amount in euro cents, excluding VAT).
2. **Empty Matches**: If no records match, return `0` (e.g. `COALESCE(SUM(...), 0)`).
3. **Periods**: Intervals are **closed on the left and open on the right**:  
   `order_date >= '2026-03-01 00:00:00' AND order_date < '2026-06-01 00:00:00'` (do **not** use `BETWEEN`).
4. **Customer Age**: Computed to the exact month and day on the given reference date (e.g., date of birth compared to reference date in the question).
